# gpio-pulse-gen

Генератор импульсов для роутера **TELEOFIS LT70** (OpenWrt) — предназначен для имитации импульсных счётчиков и тестирования входов **УСПД TELEOFIS RTU202** в режиме «сухой контакт».

```

║  GPIO Pulse Generator — TELEOFIS LT70                     ║
╚════════════════════════════════════════════════════════════╝
  Режим: РЕАЛЬНЫЙ GPIO   16:22:23   uptime 00:01:42

  Выход 1  IO1  /dev/pd0/direction
  freq=0.500 Гц   T=2000 мс   ON=1000 мс   OFF=1000 мс
   ON    ██████  Импульсов:     51   (1 л/имп)
  ВОДОСЧЁТЧИК   0 0 0 0 0 . 0 5 1   м³
  объём: 0.051 м³  (51 л)   расход: 30.00 л/мин
  ────────────────────────────────  ·▄·▄·▄·▄·▄·▄·▄·▄·▄·▄·▄·

  ────────────────────────────────────────────────────────────
  Всего импульсов: 51   Всего: 0.051 м³ (51 л)   Ctrl+C — выход
```

## Интерактивный режим

Скрипт **полностью интерактивный** — флаги командной строки не нужны. Просто запустите его, и программа спросит все параметры по шагам. Нажатие **Enter** оставляет значение по умолчанию.

```bash
python3 gpio_pulse_gen.py
```

```
  Режим симуляции (без записи в GPIO)? [д/Н]:
  Выходы IO (1–9 через запятую) [1]: 1,2
  Частота, Гц [0.5]: 0.5
  Скважность, % [50]: 50
  Литров на импульс [1]: 1
  Начальные показания счётчиков, м³ (Enter — 0):
  Выход 1 (IO1), м³ [0]: 12.345
  Выход 2 (IO2), м³ [0]: 0
  Синхронный старт всех выходов (без сдвига фазы)? [д/Н]: н
```

После настройки запускается живое табло. Выход — **Ctrl+C** (пины корректно сбрасываются в mode1).

### Шаги мастера настройки

| Запрос | По умолч. | Описание |
|---|---|---|
| Режим симуляции | нет | Симуляция без записи в GPIO (для теста без железа) |
| Выходы IO | `1` | IO пины через запятую (1–9), один или несколько. Пример: `1,2,3,4` |
| Частота, Гц | `0.5` | Частота импульсов |
| Скважность, % | `50` | Длительность ON относительно периода |
| Литров на импульс | `1.0` | Вес импульса счётчика воды, литров |
| Начальные показания, м³ | `0` | Стартовое показание счётчика по каждому выходу — счёт пойдёт от него |
| Синхронный старт | нет | Запустить все каналы одновременно (спрашивается только при ≥2 выходах) |

> По умолчанию несколько каналов запускаются **со сдвигом фазы**: при N выходах i-й сдвинут на i/N периода (для двух каналов — противофаза). Это удобно для проверки независимости каналов УСПД. Синхронный старт запускает все выходы одновременно.

`python3 gpio_pulse_gen.py --version` — показать версию.

## Эмуляция счётчика воды

Каждый импульс соответствует объёму прошедшей воды. Скрипт показывает **табло водосчётчика** — одометр в формате реального прибора: 5 чёрных барабанов (м³) и 3 красных (литры в текущем м³).

Вес импульса задаётся в мастере («Литров на импульс», по умолчанию **1 л/имп**). Начальные показания вводятся в кубометрах для каждого выхода отдельно, и накопленный объём считается **от введённого показания**.

Текущий расход рассчитывается автоматически: `freq × литров_на_импульс × 60` л/мин.

## Зачем это нужно

УСПД RTU202 считает импульсы от счётчиков воды, газа, тепла. Чтобы проверить правильность настройки УСПД и канала передачи данных **без реального счётчика**, можно использовать роутер LT70 как программируемый генератор импульсов — он подключается напрямую к входам УСПД.

## Как это работает

Роутер LT70 имеет 9 линий GPIO (IO1–IO9), каждая из которых управляется двумя sysfs-файлами через пакет `iolines-lt70`:

| Файл | Назначение |
|---|---|
| `/dev/pu{N}/direction` | pull-up |
| `/dev/pd{N}/direction` | pull-down |

Скрипт переводит выбранные пины в **mode3** (открытый коллектор: `pu=low, pd=high`) и переключает `pd` между `high`/`low` с заданной частотой и скважностью. УСПД воспринимает это как замыкание/размыкание сухого контакта.

## Подключение

```
Роутер TELEOFIS LT70        УСПД TELEOFIS RTU202
────────────────────        ────────────────────
IO1  ──────────────────────  I1+
GND  ──────────────────────  I1−

IO2  ──────────────────────  I2+   (опционально)
GND  ──────────────────────  I2−
```

> GND у всех каналов общий — достаточно одного провода на землю.

### Ограничения частоты (УСПД RTU202)

| Частота опроса УСПД | Мин. длительность импульса | Макс. частота генератора |
|---|---|---|
| 2 Гц (по умолчанию) | 500 мс | **1 Гц** |
| 20 Гц | 50 мс | **10 Гц** |

Частоту опроса УСПД меняют в RTU Configuration Tool.

## Установка

```bash
# 1. Скопируйте скрипт на роутер (например, через scp)
scp gpio_pulse_gen.py root@192.168.1.1:/root/

# 2. Сделайте исполняемым
chmod +x /root/gpio_pulse_gen.py

# 3. Запустите
python3 /root/gpio_pulse_gen.py
```

## Требования

- TELEOFIS LT70 / LT71 с OpenWrt 22.03
- Python 3.10+ (входит в стандартную прошивку LT70)
- Пакет `iolines-lt70`
- Стандартная библиотека Python — внешних зависимостей нет
