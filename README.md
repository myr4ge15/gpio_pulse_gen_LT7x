# gpio-pulse-gen

Генератор импульсов для роутера **TELEOFIS LT70** (OpenWrt) — предназначен для имитации импульсных счётчиков и тестирования входов **УСПД TELEOFIS RTU102** в режиме «сухой контакт».

```
╔════════════════════════════════════════════════════════════╗
║  GPIO Pulse Generator — TELEOFIS LT70                     ║
╚════════════════════════════════════════════════════════════╝
  Режим: РЕАЛЬНЫЙ GPIO   16:22:23   uptime 00:01:42

  Канал 1  IO1  /dev/pd0/direction
  freq=0.500 Гц   T=2000 мс   ON=1000 мс   OFF=1000 мс
   ON    ██████  Импульсов:     51
  ────────────────────────────────  ·▄·▄·▄·▄·▄·▄·▄·▄·▄·▄·▄·

  ────────────────────────────────────────────────────────────
  Всего импульсов: 51   Ctrl+C — выход
```

## Зачем это нужно

УСПД RTU102 считает импульсы от счётчиков воды, газа, тепла. Чтобы проверить правильность настройки УСПД и канала передачи данных **без реального счётчика**, можно использовать роутер LT70 как программируемый генератор импульсов — он подключается напрямую к входам УСПД.

## Как это работает

Роутер LT70 имеет 9 линий GPIO (IO1–IO9), каждая из которых управляется двумя sysfs-файлами через пакет `iolines-lt70`:

| Файл | Назначение |
|---|---|
| `/dev/pu{N}/direction` | pull-up |
| `/dev/pd{N}/direction` | pull-down |

Скрипт переводит выбранные пины в **mode3** (открытый коллектор: `pu=low, pd=high`) и переключает `pd` между `high`/`low` с заданной частотой и скважностью. УСПД воспринимает это как замыкание/размыкание сухого контакта.

## Подключение

Скрипт управляет выходами роутера (IO1–IO9) в режиме открытый коллектор. Что и куда подключать проводом — решаете вы.

```
Роутер TELEOFIS LT70        Внешнее устройство
────────────────────        ──────────────────
IO1 ──────────────────────  вход +
IO2 ──────────────────────  вход +
...
GND ──────────────────────  вход −  (общий для всех выходов)
```

> GND у всех выходов общий — достаточно одного провода на землю.

### Ограничения частоты (УСПД RTU202)

| Частота опроса УСПД | Мин. длительность импульса | Макс. частота генератора |
|---|---|---|
| 2 Гц (по умолчанию) | 500 мс | **1 Гц** |
| 20 Гц | 50 мс | **10 Гц** |

Частоту опроса УСПД меняют в RTU Configuration Tool.

## Установка

```bash
# 1. Скопируйте скрипт на роутер (например, через scp)
scp gpio_pulse_gen.py root@192.168.1.1:/root/

# 2. Сделайте исполняемым
chmod +x /root/gpio_pulse_gen.py
```

## Использование

```bash
# По умолчанию — IO1
python3 gpio_pulse_gen.py --freq 0.5

# Несколько пинов через запятую
python3 gpio_pulse_gen.py --freq 0.5 --outputs 1,2,3,4

# Любые пины в любом порядке
python3 gpio_pulse_gen.py --freq 0.5 --outputs 1,5,7,9

# Синхронный старт
python3 gpio_pulse_gen.py --freq 0.5 --outputs 1,2,3,4 --sync

# Скважность 30%
python3 gpio_pulse_gen.py --freq 2 --duty 30 --outputs 3,7

# Симуляция без реального GPIO
python3 gpio_pulse_gen.py --dry-run --freq 1 --outputs 1,2,3,4
```

### Все параметры

| Параметр | По умолч. | Описание |
|---|---|---|
| `--freq` | `0.5` | Частота импульсов, Гц |
| `--duty` | `50` | Скважность, % (длительность ON относительно периода) |
| `--outputs` | `1` | IO пины роутера через запятую (1–9). Пример: `1,2,3,4` |
| `--sync` | выкл | Запустить все выходы синхронно (без сдвига фазы) |
| `--refresh` | `0.15` | Частота обновления экрана, сек |
| `--dry-run` | выкл | Симуляция — не пишет в GPIO |
| `--version` | — | Показать версию |

> По умолчанию выходы запускаются с **равномерным сдвигом фазы** (период / N выходов). При 4 выходах: 0%, 25%, 50%, 75% периода.

## Требования

- TELEOFIS LT70 / LT71 с OpenWrt 22.03
- Python 3.10+ (входит в стандартную прошивку LT70)
- Пакет `iolines-lt70`
- Стандартная библиотека Python — внешних зависимостей нет
