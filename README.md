# gpio-pulse-gen

Генератор импульсов для роутера **TELEOFIS LT70** (OpenWrt) — предназначен для имитации импульсных счётчиков и тестирования входов **УСПД TELEOFIS RTU202** в режиме «сухой контакт».

```

╚════════════════════════════════════════════════════════════╝

  Выход 1  IO1  /dev/pd0/direction
  freq=0.500 Гц   T=2000 мс   ON=1000 мс   OFF=1000 мс
   ON    ██████  Импульсов:     51   (1 л/имп)
  ВОДОСЧЁТЧИК   0 0 0 0 0 . 0 5 1   м³
  объём: 0.051 м³  (51 л)   расход: 30.00 л/мин
  ────────────────────────────────  ·▄·▄·▄·▄·▄·▄·▄·▄·▄·▄·▄·

  Всего импульсов: 51   Всего: 0.051 м³ (51 л)   Ctrl+C — выход
```

## Эмуляция счётчика воды

Каждый импульс соответствует объёму прошедшей воды. Скрипт показывает
**табло водосчётчика** — одометр в формате реального прибора: 5 чёрных
барабанов (м³) и 3 красных (литры в текущем м³).

Вес импульса задаётся ключом `--liters-per-pulse` (по умолчанию **1 л/имп**):

```bash
# Счётчик 1 л/имп, 1 импульс каждые 2 секунды
python3 gpio_pulse_gen.py --freq 0.5 --liters-per-pulse 1

# Счётчик 10 л/имп
python3 gpio_pulse_gen.py --freq 0.5 --liters-per-pulse 10

# Тест без железа
python3 gpio_pulse_gen.py --dry-run --freq 1 --liters-per-pulse 10
```

Текущий расход рассчитывается автоматически: `freq × литров_на_импульс × 60` л/мин.

## Зачем это нужно

УСПД RTU202 считает импульсы от счётчиков воды, газа, тепла. Чтобы проверить правильность настройки УСПД и канала передачи данных **без реального счётчика**, можно использовать роутер LT70 как программируемый генератор импульсов — он подключается напрямую к входам УСПД.

## Как это работает

Роутер LT70 имеет 9 линий GPIO (IO1–IO9), каждая из которых управляется двумя sysfs-файлами через пакет `iolines-lt70`:

| Файл | Назначение |
|---|---|
| `/dev/pu{N}/direction` | pull-up |
| `/dev/pd{N}/direction` | pull-down |

Скрипт переводит выбранные пины в **mode3** (открытый коллектор: `pu=low, pd=high`) и переключает `pd` между `high`/`low` с заданной частотой и скважностью. УСПД воспринимает это как замыкание/размыкание сухого контакта.

## Подключение

```
Роутер TELEOFIS LT70        УСПД TELEOFIS RTU202
────────────────────        ────────────────────
IO1  ──────────────────────  I1+
GND  ──────────────────────  I1−

IO2  ──────────────────────  I2+   (опционально)
GND  ──────────────────────  I2−
```

> GND у всех каналов общий — достаточно одного провода на землю.

### Ограничения частоты (УСПД RTU202)

| Частота опроса УСПД | Мин. длительность импульса | Макс. частота генератора |
|---|---|---|
| 2 Гц (по умолчанию) | 500 мс | **1 Гц** |
| 20 Гц | 50 мс | **10 Гц** |

Частоту опроса УСПД меняют в RTU Configuration Tool.

## Установка

```bash
# 1. Скопируйте скрипт на роутер (например, через scp)
scp gpio_pulse_gen.py root@192.168.1.1:/root/

# 2. Сделайте исполняемым
chmod +x /root/gpio_pulse_gen.py
```

## Использование

```bash
# Один канал — IO1, 1 импульс каждые 2 секунды
python3 gpio_pulse_gen.py --freq 0.5 --outputs 1

# Два канала — IO1 и IO2, в противофазе
python3 gpio_pulse_gen.py --freq 0.5 --outputs 1,2

# Четыре канала синхронно
python3 gpio_pulse_gen.py --freq 0.5 --outputs 1,2,3,4 --sync

# Высокая частота со скважностью 30%
python3 gpio_pulse_gen.py --freq 2 --duty 30 --outputs 3

# Симуляция без реального GPIO (для теста без железа)
python3 gpio_pulse_gen.py --dry-run --freq 1
```

### Все параметры

| Параметр | По умолч. | Описание |
|---|---|---|
| `--freq` | `0.5` | Частота импульсов, Гц |
| `--duty` | `50` | Скважность, % (длительность ON относительно периода) |
| `--liters-per-pulse` | `1.0` | Вес импульса счётчика воды, литров |
| `--outputs` | `1` | IO пины через запятую (1–9), один или несколько. Пример: `1,2,3,4` |
| `--sync` | выкл | Запустить все каналы синхронно (без сдвига фазы) |
| `--refresh` | `0.15` | Частота обновления экрана, сек |
| `--dry-run` | выкл | Симуляция — не пишет в GPIO |
| `--version` | — | Показать версию |

> По умолчанию несколько каналов запускаются **со сдвигом фазы**: при N выходах i-й сдвинут на i/N периода (для двух каналов — противофаза). Это удобно для проверки независимости каналов УСПД. Флаг `--sync` запускает все выходы одновременно.

## Требования

- TELEOFIS LT70 / LT71 с OpenWrt 22.03
- Python 3.10+ (входит в стандартную прошивку LT70)
- Пакет `iolines-lt70`
- Стандартная библиотека Python — внешних зависимостей нет
