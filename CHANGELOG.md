# Changelog

## [1.2.0] — 2026-06-30

### Добавлено
- Полностью интерактивный режим: все параметры (выходы, частота, скважность, вес импульса, режим, синхронность) запрашиваются по шагам — флаги командной строки больше не нужны
- Ввод начальных показаний счётчика по каждому выходу в м³ — накопленный объём считается от введённого значения
- Защита от зависания при неинтерактивном запуске (EOF → значения по умолчанию)

### Изменено
- Конфигурация через argparse заменена интерактивным мастером (`--version` сохранён)

## [1.1.0] — 2026-05-19

### Добавлено
- Эмуляция реального счётчика воды: табло-одометр (5 чёрных барабанов м³ + 3 красных литры)
- Ключ `--liters-per-pulse` — вес импульса в литрах (по умолчанию 1.0 л/имп)
- Отображение накопленного объёма (м³ и л) и текущего расхода (л/мин) по каждому каналу
- Итоговый объём по всем каналам в сводной строке
- Ключ `--outputs` — произвольный список IO пинов (1–9) через запятую вместо `--io1/--io2`; поддержка до 9 каналов одновременно с равномерным сдвигом фазы (i/N периода)

### Исправлено
- Двойной вызов завершения при Ctrl+C/SIGTERM (теперь `shutdown` идемпотентен)
- Обработчики сигналов регистрируются до блокирующих предупреждений `check_freq`, чтобы Ctrl+C всегда корректно сбрасывал пины
- Выравнивание правой границы рамки заголовка

## [1.0.0] — 2026-05-19

Первый публичный релиз.

### Добавлено
- Генерация импульсов на линиях GPIO роутера LT70 (sysfs `iolines-lt70`, режим открытого коллектора mode3)
- Настройка частоты и скважности импульсов
- Живое табло состояния выходов в терминале
- Режим симуляции `--dry-run` для проверки без железа
- Корректный сброс пинов и завершение по Ctrl+C
